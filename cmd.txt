### Android
Build the application bundle:
 - `./kotlin build -m androidApp -p android -v debug`

Run Android UI tests from Android Studio on a connected device or emulator.

### Desktop
Run the desktop application: `./kotlin run -m desktopApp`
Package the desktop application as an executable JAR: `./kotlin package -m desktopApp`
Run JVM tests: `./kotlin test -m shared -p jvm`
Native DMG/MSI/DEB installers remain outside the current Kotlin Toolchain product.

### iOS
Open `DemoApp/iosApp/module.xcodeproj` in Xcode and run the standard configuration.
The Xcode build phase invokes the Kotlin Toolchain integration for the shared framework.

### JS Browser (Experimental)
Build and assemble the browser distribution: `./scripts/package-js-browser.sh`
Serve `build/jsApp-browser` over HTTP and open its `index.html` in a browser.
The Kotlin Toolchain does not package `js/app` automatically; the script adds the
Skiko JS runtime and Compose resources required by this Compose demo.

### Wasm Browser (Alpha)
Run the application locally: `./kotlin run -m webApp`
Build the deployable package: `./kotlin build -m webApp -p wasmJs -v release`
Wasm tests are not supported by the Kotlin Toolchain yet.
