
### Android
To run the application on android device/emulator:  
 - open project in Android Studio and run imported android run configuration

To build the application bundle:
 - run `./gradlew :DemoApp:androidApp:assembleDebug`
 - find `.apk` file in `DemoApp/androidApp/build/outputs/apk/debug/androidApp-debug.apk`
Run android UI tests on the connected device: `./gradlew :DemoApp:androidApp:connectedDebugAndroidTest`

### Desktop
Run the desktop application: `./gradlew :DemoApp:desktopApp:run`
Run desktop UI tests: `./gradlew :DemoApp:shared:jvmTest`

### iOS
To run the application on iPhone device/simulator:
 - Open `DemoApp/iosApp/iosApp.xcodeproj` in Xcode and run standard configuration
 - Or use [Kotlin Multiplatform Mobile plugin](https://plugins.jetbrains.com/plugin/14936-kotlin-multiplatform-mobile) for Android Studio
Run iOS simulator UI tests: `./gradlew :DemoApp:shared:iosSimulatorArm64Test`

### JS Browser (Experimental)
Run the browser application: `./gradlew :DemoApp:webApp:jsBrowserDevelopmentRun --continue`
Run browser UI tests: `./gradlew :DemoApp:webApp:jsBrowserTest`

### Wasm Browser (Alpha)
Run the browser application: `./gradlew :DemoApp:webApp:wasmJsBrowserDevelopmentRun --continue`
Run browser UI tests: `./gradlew :DemoApp:webApp:wasmJsBrowserTest`
